# Indian Number Place value Game

A polished Vite + React learning game for teaching children the Indian number system: Ones, Tens, Hundreds, Thousands, Lakhs and Crores.

## Stack

- React
- Vite
- motion/react
- CSS
- Browser Speech Synthesis API

## Features

- Independent vertical roll-up digit animation with Motion.
- Previous / Next / Play / Pause / Go to 0 controls.
- Adjustable animation speed from 0.25× to 2×.
- Adjustable voice speed and Indian English voice selection when the browser provides one.
- Pronunciation of Indian-format numbers up to 9,99,99,999.
- Visual place-value groups and carry/borrow explanation.
- Responsive typography and controls for desktop, tablet and mobile.
- Game dropdown for Place Value, Read & Say, and Carry & Borrow learning modes.
- Keyboard shortcuts: Left Arrow, Right Arrow, Space and Home.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The project intentionally does not include `node_modules` in the ZIP. Run `npm install` after extracting it.
